Multi-Factor Challenge

When policy requires it, complete MFA before identity context is accepted. Administrators and staff require multi-factor authentication in the product scope.

Input

Authentication policy indicates an additional factor is required.

Service boundary

The production identity provider performs the MFA challenge; the UI must not invent or locally validate factors.

Output

Verified authentication continues to person resolution, or access fails closed.

Provider-dependent action is fail-closed.No credential submission, MFA verification, session creation or authentication success is fabricated until a production identity provider is selected and connected behind the governed service interfaces.

Source-backed responsibility

Multi-Factor Authentication is a governed Identity / Access lifecycle destination; the product scope requires MFA for administrators and staff.
