# Workflow State Authority

## Individual song journey

Inquiry → Request → Qualified → Awaiting Payment → Interview Scheduling → Story Capture → Story Development → Lyric Development → Customer Review → Approved for Production → Production → Quality Review → Final Approval → Delivered → Closed.

Exceptions such as declined, cancelled, failed payment, awaiting customer, consent blocked, production blocked and refunded will be modeled explicitly when their repositories/services are implemented.

## Project Ageless program run

Lead → Consultation → Scope & Funding → Contracted → Facility Onboarding → Participant Enrollment → Consent Readiness → Active Program → Song Development → Event Readiness → Concert → Keepsake Delivery → Outcome Measurement → Closeout.

Participant attendance is independent of the overall program state. A participant is not required to attend every touchpoint.
