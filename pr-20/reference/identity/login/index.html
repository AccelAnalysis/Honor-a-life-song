Login workflow nodes

Provider boundary

Sign In

Begin the server-authoritative authentication handoff without storing or validating credentials in the presentation shell.

  • Identity Provider HandoffAuthenticate with the selected production identity provider and return a normalized authenticated identity result to the platform services.
  • Multi-Factor ChallengeWhen policy requires it, complete MFA before identity context is accepted. Administrators and staff require multi-factor authentication in the product scope.
Chassis contract

Resolve Access

Translate the authenticated provider identity into the platform's canonical person, membership, role and organization context.

  • Authenticated PersonResolve the provider identity to the canonical Person record rather than creating a second identity model inside the login UI.
  • MembershipsResolve the person's platform and organization memberships that establish the contexts in which the person may act.
  • RolesResolve the roles granted through membership using the canonical customer, family collaborator, authorized representative, facility staff, creator and admin role vocabulary.
  • Organization ContextResolve the active organization when the person's membership is scoped to a facility or another supported organization context.
Chassis contract

Enter Workspace

Complete authorization by resolving which governed authenticated workspace destinations are permitted for the identity context.

  • Permitted WorkspacesAuthorize only the Customer, Facility, Creator or Admin workspace destinations included in the resolved identity context.
