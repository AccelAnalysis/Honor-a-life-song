# Apple HIG references used for the SongKeep Customer Pipeline presentation

The redesign was checked against the current Apple Human Interface Guidelines, including:

- Design principles: Purpose, Agency, Responsibility, Familiarity, Flexibility, Simplicity, Craft, and Delight.
- Accessibility: intuitive/perceivable/adaptable interfaces; contrast; non-color-only state cues; larger text; sufficiently sized controls; familiar interactions; reduced-motion behavior.
- Color: restrained and consistent color use; brand color as accent rather than background chrome; avoid relying on color alone.
- Branding: brand identity should defer to content and use familiar platform patterns consistently.
- Boxes and grouping: prefer padding/alignment and avoid nested boxes that make the interface feel busy and constrained.

Primary reference: https://developer.apple.com/design/human-interface-guidelines/
