# Security and Accessibility Baseline

## Security

- No secrets in source control.
- Production identity and authorization are server-authoritative.
- Consent is evaluated separately from role authorization.
- Participant/family/facility data is scoped by least privilege.
- Sponsor funding does not create participant-data access.
- Media delivery requires entitlement and consent checks.
- Material changes and downloads should emit audit events once persistence is connected.

## Accessibility

The chassis establishes mobile-first responsive composition, semantic landmarks, visible focus, readable defaults, large touch targets and explicit status text. Downstream workflows must target WCAG 2.2 AA and support assisted workflows where participants do not have email, smartphones or independent digital access.
